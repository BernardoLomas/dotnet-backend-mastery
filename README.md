# .NET Backend Mastery

Personal learning repository focused on becoming a professional
Backend Engineer using C# and .NET.

## Goals

- Master the C# language
- Understand the .NET runtime
- Build strong Computer Science fundamentals
- Master ASP.NET Core
- Master relational databases and data access
- Learn professional testing practices
- Understand software design and architecture
- Learn security, cloud, observability and distributed systems
- Build production-ready backend applications

## Method

For every subject:

1. Understand the problem
2. Study the theory
3. Read authoritative sources
4. Implement a small lab
5. Solve exercises without assistance
6. Apply the concept to a real project
7. Test the implementation
8. Explain trade-offs
9. Review the topic later
